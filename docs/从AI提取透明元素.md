# 从 AI 提取透明元素

**场景**:设计给的是启动页 `.ai`(整张画面、统一深色底),需要拆出图标 / 逐字 Logo / 逐字副标题,
每个元素独立成透明 PNG 才能分别做动画。
**结论**:整页超采样渲染 + **背景反解 alpha** + 裁可见内容 + 对称补边距。

## 1 为什么不能直接"导出资产"

`.ai` 里通常是**一个整页矢量稿**:元素彼此重叠、没有分组导出、颜色是 CMYK/专色。
AI 自带的"导出为 PNG"只能整页导出,拆不开。要拆,只能**自己算**:
渲染整页 → 与背景色求差 → 差值即 alpha。

## 2 算法

```
1) PyMuPDF 打开 page,scale=2 渲染成 RGB(超采样,给边缘 AA)
2) 背景色 = 四角 4px 的中位数(不手填)
3) diff   = |RGB - bg| 的逐像素最大通道差
4) norm   = 单元格内 diff 的 99.5 分位(避开极亮噪点)
   alpha  = clip(diff / norm, 0, 1)
5) 裁到 alpha > 0.02 的包围盒(可见内容)
6) 缩到输出尺度(必须与合成像素空间一致)
7) 四周补 pad 像素透明边距
```

关键在 **3→4**:背景是纯色 ⇒ 差值完全来自前景;`norm` 取分位而不是最大值,避免单个高光把整体压暗。

## 3 为什么顺序不能换

```
裁到可见内容  →  缩到输出尺度  →  补对称透明边距
```

| 换顺序 | 后果 |
|---|---|
| 先补边距再缩放 | 边距被缩掉,`cx/cy` 与文件尺寸全错 |
| 先缩放再裁 | 边缘丢 1–2px,细笔画(如副标题的横)会被削 |
| 不做第 5 步 | 边距左右不等 ⇒ `文件中心 ≠ 内容中心` ⇒ 图层摆上去整体偏 |

实测:交付资产 `logo_1.png` 是 `184×194`,alpha bbox 从 `(56,56)` 到 `(128,138)` ——
四周正好 56,`184 = 72 + 56 × 2`。**这就是"对称边距"的读数证明**。

## 4 取单元格:自动 vs 显式

- **自动**(`--gap 16`):行投影分带 → 带内列投影切块。
  副标题字间距够大,能自动分开(实测逐字 `~90×90`,交付 `~147×148`);
  **Logo 整体会被切开或并错**(实测自动给 `371×137`,交付是 `577×239`)⇒ 逐字/整体必须显式。
- **显式**(`--cells cells.json`):`bbox` 用 **1x 页面坐标**,最可控。

交叉验证:自动跑一遍看结构 → 显式定框交付 → 两边 `cx` 差 > 1px 就是框错了。

## 5 实测(QQ音乐启动页,页面 2048×1152 pt)

| 元素 | 尺寸(交付) | cx / cy |
|---|---|---|
| icon | `238×239` | `855.75 / 541` |
| logo 四字 | `184×194` 起 | `977.75 / 1056.75 / 1138.75 / 1220.5`,cy≈541 |
| logo_full | `577×239` | `1025 / 541` |
| tag 逐字 | `~147×148` | cy≈659 |

三个品牌 `logo_full`:QQ `577×239`、K歌 `574×240`、懒人 `575×237` —— 差异来自字形宽度,不是误差。

`cx/cy` 与在 AE 里量到的末帧包围盒**互相印证**:QQ 末帧 bbox `792–1256 / 477–677`,
中心 `(1024, 577)`;`logo_full` 中心 `1025` ⇒ 差 1px,由字形左右留白造成。

## 6 局限(必须提前告知)

| 局限 | 原因 | 处理 |
|---|---|---|
| 发光/投影被扣进 alpha | 差值法看不到"哪些差值属于发光" | 设计稿里关效果重导,或接受并在 AE 里另做 |
| 真半透明元素被归一化到不透明 | `norm` 把 30% 白拉成 100% 白 | `--unpremultiply` + 肉眼复核 |
| 浅底 / 反色不适用 | 深色图形在浅底上差值也大,但语义反了 | 换算法(`alpha = 1 - diff/norm`) |
| 未转曲文本渲染成方框 | 字体缺失 | 设计侧转曲 |

## 7 坑

- **`page.rect` 是 pt,不是设计 px**。先跑一次看 `1x WxH` 是否等于合成尺寸,再定 `--out-scale`。
  混淆 `--scale` 与 `--out-scale` ⇒ 所有尺寸差一倍(表现为 `cx` > 合成宽度,一眼可见)。
- **阈值 8 是经验值**。调到 2 会把背景噪点算成内容;调到 30 会吃掉细笔画。
- 文件名会 `sanitize`(非 `\w` → `_`);元素名建议 ASCII。
- 抽出来的 PNG **不要改尺寸**去适配图层 —— 尺寸变了 `cx/cy` 就失效,应该改合成或改 `--out-scale`。
