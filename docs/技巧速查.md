## §1 通道:怎么让 AE 干活而不点界面

| 事 | 做法 |
|---|---|
| 跑脚本 | `AfterFX.exe -r <jsx>`(**必须等主窗口就绪**,否则静默丢脚本) |
| 建工程 | `app.newProject()` |
| 存盘 | `app.project.save(new File(path))` |
| 退出 | `app.quit()`(这是"跑完了"的唯一信号) |
| 回传 | 日志文件,**逐行 open/append/close** |
| 抽帧 | `comp.openInViewer()` + `comp.saveFrameToPng(t, file)`(**异步**) |

**核心限制**:AE 没有常驻脚本通道 ⇒ **一次 `.jsx` 必须把所有事做完**,中间状态只能落盘。

深入: [`无头运行AE脚本.md`](无头运行AE脚本.md) / 脚本 [`../scripts/ae-headless-run/`](../scripts/ae-headless-run/)

## §2 工程结构:一个合成该长什么样

```
合成 2048×1152 / 30fps / 3s
├── 参数控制      ← solid,置顶,挂 10 个滑块(锁定除外)
├── 图层1..n      ← PNG footage,Position 摆到 (cx, cy),挂表达式
└── BG           ← solid #0F0F11,置底,locked = true
```

- **背景锁定**:抽帧/审阅时不会误选,也避免被表达式带动。
- **参数控制置顶**:所有图层都用 `thisComp.layer("参数控制")` 找它,名字必须稳定。
- **滑块按索引取**:中文界面下 `effect("Slider")` 是 `null`,用 `effect(1)`。
- **自己命名的中文滑块**在表达式里**可以按中文名**取(界面语言一致时),这点与默认英文名不同。

深入: [`../scripts/comp-builder/README.md`](../scripts/comp-builder/README.md)

## §3 动画:表达式而不是关键帧

`setTemporalEaseAtKey` 在 AE 2026 对多维亚属性**不可用**(Position 报错 / Scale 硬崩进程 / 退到 1 个 ease 仍崩)。
⇒ 动画一律用表达式:

```
u = clamp((time - delay) / dur, 0, 1)
f = cubicBezier(u, x1, y1, x2, y2)      // 二分反解,和 CSS 同语义
Property = base ± 位移 * (1 - f)  /  Opacity = 100 * f  /  Scale = from + (100-from)*f
```

- 时长/延迟/错位全在**滑块**上,改参数不用重打关键帧;
- `value` 是图层摆好的基准位置 ⇒ 位移写成 `value + dy - dy*f`,**不要写绝对坐标**。

深入: [`表达式缓动与滑块控制.md`](表达式缓动与滑块控制.md) / 脚本 [`../scripts/expression-tween/`](../scripts/expression-tween/)

## §4 核验:怎么证明"做对了"

| 判据 | 读数 |
|---|---|
| 抽帧真的落盘 | 日志里 `exists=true`,且磁盘数 = 期望数 |
| 表达式没错 | `expressionError` 递归扫描 = 0 条 |
| 位置对 | 末帧非背景 bbox 在期望包围盒 ±4px |
| 参数生效 | 改滑块前后同时间点抽帧,bbox 必须变 |
| 动画在动 | 同一合成像素数随时序单调不减(回弹方案除外) |

**不要用 md5 判"两张图一样"**:PNG 带时间戳块,md5 不同而像素可以完全相同。

深入: [`抽帧核验.md`](抽帧核验.md) / 脚本 [`../scripts/frame-verify/`](../scripts/frame-verify/)

## §5 素材:从设计稿到 PNG

```
.ai/.pdf  --PyMuPDF scale2 渲染-->  整页 RGB
          --与背景色求差-------->  alpha
          --裁可见内容---------->  缩到输出尺度 --> 补 56px 透明边距
```

- 只适用**深色统一底**;浅底/反色不适用。
- 顺序 `裁 → 缩 → 补边距` 不能换,否则 `cx/cy` 与尺寸全错。
- 自动切块只能看结构;**交付用 `--cells` 显式框**(逐字拆分必须显式)。

深入: [`从AI提取透明元素.md`](从AI提取透明元素.md) / 脚本 [`../scripts/vector-extract/`](../scripts/vector-extract/)

## §6 排查:按命中率排序

| # | 现象 | 先查 |
|---|---|---|
| 1 | AE 进程直接消失 | 是否把 **AE 对象**拼进了字符串(`+ viewer` / `+ 返回值`) |
| 2 | 日志为空,像没跑 | 冷启动是否**没等主窗口**就 `-r`;日志是否**没逐行落盘** |
| 3 | 日志成功、文件不存在 | 抽帧是**异步**;缺 `$.sleep`;文件名是否非 ASCII |
| 4 | `null is not an object` | 中文界面按**英文名**取了默认属性 ⇒ 改按索引 |
| 5 | 表达式全报错 | 表达式里是否用了 `//` 注释(拼接后会把后半段注释掉) |
| 6 | 图层位置整体偏 | 素材透明边距**左右不等** ⇒ 中心不是内容中心 |
