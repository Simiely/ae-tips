# vector-extract · 从 `.ai` / `.pdf` 设计稿拆透明元素

把一张启动页设计稿拆成**可独立做动画的 PNG**(图标、逐字 Logo、副标题逐字),并输出 `elements.json` 供
`comp-builder` 组工程。

## 前提

**统一深色底 + 亮色图形**。原理是"背景反解":渲染整页 → 取背景色 → 逐像素与背景求差 → 差越大越不透明。

浅底、反色、多色渐变底**不适用**(差值法在浅底上会把"深色图形"判成背景)。

## 用法

```bash
# 自动切块(快速看有哪些元素)
python extract_assets.py page.ai --out out/QQ音乐 --prefix QQ

# 指定单元格(推荐;逐字拆分也靠它)
python extract_assets.py page.ai --out out/QQ音乐 --prefix QQ --cells cells.json
```

`cells.json`(`bbox` 用 **1x 页面坐标 / pt**):

```json
[
  { "name": "icon",   "bbox": [775, 476, 936, 607] },
  { "name": "logo_Q", "bbox": [938, 482, 1018, 601] },
  { "name": "tag_1",  "bbox": [770, 620, 826, 700] }
]
```

参数:

| 参数 | 默认 | 说明 |
|---|---|---|
| `--scale` | 2.0 | **超采样**倍率(只影响边缘 AA 质量) |
| `--out-scale` | 1.0 | 输出像素 / 页面 pt 的倍率,**必须与合成像素空间一致** |
| `--pad` | 56 | 四周透明边距,**输出**像素 |
| `--thresh` | 8 | 非背景阈值 |
| `--gap` | 16 | 自动切块的列间隙(1x pt) |
| `--min-area` | 400 | 自动切块的最小墨迹面积 |
| `--unpremultiply` | 关 | 半透明边缘反预乘(`F = B + (C-B)/a`) |

## 输出

```
out/QQ音乐/
├── QQ_icon.png        # RGBA,可见内容居中,四周 56px 透明
├── QQ_logo_Q.png
└── elements.json      # {meta, elements:[{file,name,w,h,cx,cy}]}
```

`cx/cy` 是**元素中心在合成坐标**下的位置(即 `out_scale` 空间),`comp-builder` 直接用它摆图层。

## 三个顺序不能错

```
裁到可见内容  →  缩到输出尺度  →  补对称透明边距
```

- 先补边距再缩放:边距会被一起缩掉,`cx/cy` 与文件尺寸全部对不上;
- 先缩放再裁:边缘会被裁掉 1–2px;
- **裁到可见内容**是必需的:只有边距左右对称,`文件中心 == 可见内容中心` 才成立,
  否则图层摆上去会整体偏移。

## 实测(QQ音乐启动页 `835_启动页`,页面 2048×1152 pt)

| 元素 | 自动切块 | 交付资产(`--pad 56`) | 备注 |
|---|---|---|---|
| 图标 | `182×182` | `238×239`,alpha bbox 从 `(56,56)` 起 | 内容 `126×127` |
| Logo 整体 | `371×137` | `577×239` | **自动切块会把字间距并进来**,逐字/整体要以 `--cells` 给定 |
| 副标题逐字 | `~90×90` | `~147×148` | 内容 `91×91`,字间距够大,自动切块能分开 |

`cx/cy` 与设计稿量出的中心**逐位一致**:icon `855.75 / 541`,logo 四字 `977.75 / 1056.75 / 1138.75 / 1220.5`。

> 交叉验证的做法:同一份设计稿**先自动切块看结构,再用 `--cells` 定框交付**;
> 两边的 `cx` 差 >1px 就说明框给错了。

## 局限

- **发光/投影会被一起扣进 alpha**。若后期要去掉发光(本项目就是),要么在设计稿里关掉效果再导出,
  要么接受它并在 AE 里用不透明度/模糊另行处理。
- **半透明元素**(如 30% 白的中文副标题)alpha 会被归一化放大到 1,颜色也随之变亮。
  需要真半透明时用 `--unpremultiply`,并**肉眼复核**。
- **文字被转曲才可靠**。未转曲的文本在某些 `.ai` 里渲染成方框。

## 坑

- `.ai` 用 PyMuPDF 打开时,`page.rect` 是**pt**,与设计稿的 px 不一定 1:1。
  先跑一次打印 `1x WxH`,确认与合成尺寸一致,再决定 `--out-scale`。
- `--out-scale` 与 `--scale` 混淆会让所有尺寸差一倍 —— 输出里 `cx` 会明显大于合成宽度,一眼能看出来。
- **文件名会做 `sanitize`**(非 `\w` 换成 `_`);中文元素名建议直接用 `--cells` 里的 `name` 写 ASCII。
